# CNCF 阿里云原生公开课课件

本目录包含30章课件 PDF。最初保存的课程只读预览页共589页，预览元数据共639页；部分章节中途无法继续加载，原始缺失范围见 [manifest.json](manifest.json) 的 `expected_pages` 和 `preview_pages`。课程预览页面禁止下载、另存和打印，未对受限页面绕过限制。

已将有明确插入位置的补充材料放入章节序列：第3章配图替换原PDF第6页空白捕获页；第8章4张配图替换原PDF第20–22页空白捕获页并按图序排列；第27章已核实的第31、32页插在总结页之前。合并后30章主 PDF 共592页。其他章节的公开图文配图没有可核实的原课件连续页码，且部分与现有课件内容重合，因此保留在独立补充集中，不标作已插入原课件。原预览器的缺页统计仍见 `expected_pages`，它不能用于推断这些配图的原始页序。

补充材料来源、插入章节和位置说明见 [manifest.json](manifest.json)。原始10份受影响章节 PDF 已备份在 `原始预览备份`；独立补充集仍保存在 `公开课图文版课件补充集.pdf`，官方公开课件第31、32页也保留在 `27-Kubernetes安全之访问控制-官方公开课件补页31-32.pdf`。
